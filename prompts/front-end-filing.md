# Front-End Filing Prompt

Use this ONCE per account to set up self-filing. After that the
file-this-chat skill handles it and you never run a cleanup again.

---

Set up a filing system that works at the FRONT end, not as cleanup later.

The problem: I clean up every few days and it never sticks. I lose
whole afternoons clicking between tabs trying to find where we left off.

Build it this way:

1. FILE AT THE START, NOT THE END.
   The moment you know what a chat is about, rename it. Before doing
   any work. A chat renamed "later" never gets renamed.

2. THE TITLE IS THE FILING SYSTEM.
   Tags and labels I cannot see are useless to me. Put the subject in
   the title as an uppercase prefix so my sidebar groups itself:

       PREFIX — what this is about

3. USE A FIXED REGISTRY. Never invent a prefix.
   List my actual subjects here and use only these:
   [YOUR SUBJECTS]

4. KEEP A LOG OUTSIDE THE CHAT.
   One line per session in a file: date, prefix, what happened, what
   is blocking it. When I ask where I left off, read the log. Never
   tell me to scroll back through a conversation.

5. ONE SUBJECT PER CHAT.
   If a chat drifts into a second subject, finish the thought, then
   tell me it belongs in a new chat and name it for me.

Make this a skill that triggers on plain language, so it fires when I
name a project or say "file this" or "where did we leave off". I will
not remember a command.

Do not report the filing to me as an accomplishment. File it and get
on with the actual work.

# Ironbridge Strategy Group

## Communication style

Write every response in the Google developer documentation style. Load
`.claude/skills/google-dev-docs-style/SKILL.md` at the start of a session and
follow it for chat replies, commit messages, PR descriptions, and any document
you produce.

The short version: answer first, use second person and present tense, keep
sentences under about 26 words, cut hype and filler, and name the file, command,
or line behind every claim.

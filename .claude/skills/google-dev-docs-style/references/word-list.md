# Word list

Substitutions from the Google developer documentation style guide word list and
its inclusive-language guidance. Load this file when you're editing text or you
need to check a specific term.

## Filler and hype — cut these

| Don't write | Write |
| --- | --- |
| simply, just, easy, easily, quick, obviously, of course, clearly | (delete it) |
| powerful, robust, seamless, blazing fast, world-class, cutting-edge | what it actually does |
| please (in instructions) | (delete it) |
| note that, it's worth noting that | (delete it, or use a Note callout) |
| in order to | to |
| utilize, leverage | use |
| allows you to, enables you to | lets you |
| via | with, through, by using |
| a number of, several | the number |
| at this time, currently, right now, soon, new | (delete it, or give a date) |

## Verbs for UI actions

- **click** — a button, link, or menu item with a mouse.
- **tap** — the same action on a touchscreen.
- **select** — an item from a list or a checkbox you turn on.
- **clear** — a checkbox you turn off.
- **enter** — text you type into a field.
- **specify** — a value you set, wherever you set it.
